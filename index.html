Introduction

Welcome!

Hello! welcome to the step-by-step guide of making a full animation doing the best to mimic a professional workflow in open-source! Just a few notes before we start:

  • This is an ALPHA. So things are still a bit rough around the edges and continually being updated (hopefully you all can help with making it better!)
  • Not everything in this project is open-source there were two software I struggled replacing. Storyboard Pro (Which I will experiment replacing with blender after the 5.0 update that includes a dedicated Storyboarding workplace) and Davinci Resolve (While I used the free version of Davinci for this entire process, it is not an open-source project. There are simply no great FOSS alternatives to Davinci's Fusion tab that I could find right now.
  • I will NOT be talking about basic fundamentals so, no explanations on how to 2D animate, 3D model, digital painting etc. This guide is more about explaining niche features and interoperability between software.

Who's It For

This is mostly appealing toward frame-by-frame animators who use 3D in their process, specifically for backgrounds and props. Full 3D animators probably won't find much use in this. 2D puppet animators mileage will vary as well as there are not really any FOSS alternatives for the 2D puppet animation workflow.

Alright let's get started!

Hardware & Troubleshooting/Glitches

The Hardware used in this process was as followed:

  • MacBook Pro M1 Pro 16gb ram
  • iPad pro M1
  • Wacom Movink pad (Only used as an alternative for iPad)

I have done my best to document any of the glitches and troubleshooting I had in this process as well as providing my solutions to them. For people using other operating systems. I would love if the community can source these in the future!

Software

The software used in this process is as followed everything should still in theory be the same in new versions of these softwares. I will try to keep things updated as well as hopefully get help from the greater community if there are big changes going forward:

  • Storyboard Pro '25
  • Blender 4.5
  • Krita 5.2.13
  • Opentoonz 1.7.1/Tahoma2D 1.6
  • Davinci Resolve 22

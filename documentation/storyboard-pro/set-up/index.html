Set Up

Here is a basic set up of Storyboard Pro. It has an infinite canvas which helps with planning camera moves. For this we will be focusing on how to draw in 3D for this scene.

Note: Storyboard Pro 3D workflow/load

A file can become really heavy if you have a lot of drawn 3D layers. If you have a 3D model you can use for your scene this will probably much lighter on the program.(I have not tried inserting 3D models directly into Storyboard Pro yet and the guide will be updated when it is) It is based on if you want to mock up or 3D or 2D first.

First set up the windows that will be needed for a 3D scene:

  • Timeline
  • Camera View
  • Stage View
  • Top view
  • Side View

These can all be found in the window option or in the plus section of some of the windows already open.

Next to turn the storyboard scene in to 3D, press this button in the top bar:

Note

If you don't see the 3D icon, press the arrows which will expand all setting at the top. If the 3D is grayed out this means your scene is already in 3D

When enabled, toggling to Stage View shows your drawings in a 3d space. Every layer in Storyboard Pro sits flat in 3D space. You can hold [space] to pan around in Stage view and holding [Cmd/Ctrl +Shift] lets you orbit around a 3D scene. Clicking and holding the hand tool on the side also allows you to switch between the two

Tip

The zoom tool is also available in the drop down as well. It is a good idea to map it to a key command (i.e 1 and 2 for zooming in and out)

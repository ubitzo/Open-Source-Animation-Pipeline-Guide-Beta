Stylized Lighting

After completing the model it can be lit dynamically with painterly lighting using the Stylized Asset Suite Add on:

Setting up the Texture

Once the desired texture is reached:

  • Press [N] on the keyboard to bring up the N Side Panel
  • Navigate to Ucupaint and select your desired object
  • In the Channels drop down (above the Layers drop down) find the Color Channel box and press the gear icon
  • Select "Bake Color Channel"

Note

  • This will turn all your layers made on one object into one flattened texture
  • Remember the name of this texture
  • To change the name of the baked image texture go into the Texture paint tab and at the top there is click on your selected texture and select the box to change the name
  • You can switch back from to your unbaked images by clicking the "Use Baked" button in UCUpaint
  • If you add additional edits to your texture press the "Rebake" button to add changes to the baked image

Warning

If parts of your model turn pink after baking the image that means you have baked them to the wrong UVs double check you have the right UV selected in the layer mode as well as if your object is currently rendering the correct UV in the object data tab (the green triangle in the properties tab on the right of the UI


MAKE SURE TO SAVE YOUR TEXTURES

Adding the Stylized Light Set Up

  • With "N Panel" Still open, select the "Stylized Asset Suite"
  • Click on the "Add Material Slot" near the top of the panel
  • Go all the way to the top of the panel and click on "New" to create a new material slot for your object
  • Press [tab] on the keyboards to switch to "Edit Mode"
  • Press [A] to select the entire model (If it does not automatically happen when pressing tab)
  • Under the new material box press on "Assign Material"
  • Press [tab] to switch back to object mode

Reapplying Texture

  • With the "Stylized Asset Suite" go to the "Select Effect" drop down
  • Select the "Texture Paint/ Draw (All colors)" options in the "Hand Drawn Texturing" section
  • Click the "Add effect" button to create the effect mode
  • With the Texture Paint effect created click on the "▶︎" to expand the options
  • In the "Drawing Texture:" row click on the image drop down symbol
  • Find and select the texture made previously in Ucupaint

Note

If your textures are wrong when opening onto the model make sure to double check your model are rendering the correct UVs

Info

You might notice you can link and do all of the screen grab painting in this texture paint mode as well. The reason I decided not to do texture painting in Stylized Asset Suite is that:

  1. Ucupaint gives you infinite layers, if you are using the free version of Stylized Asset Suite (SAS) you are limited to a set amount of layers
  2. Ucupaint is more stable (at least for mac) I've often had crashes while using SAS especially when trying to swap effects around
  3. Ucupaint allows you select the UV for each layer we paint on allowing us to do our earlier process
  4. Ucupaint also has a lot of useful layer features (edge detect, brick patterns etc.)

Applying Stylized Lighting

  • Once again, go to the "Select Effect" button and click it
  • Select "Stylized 3D Lighting Main (Dynamic) (EEVEE) and click "Add Effect"
  • With the Stylized 3D Lighting effect created click on the "▶︎" to expand the options

Painterly Lighting Set Up Example

  • In the "Stylized 3D Lighting Main (Dynamic)" which has multiple controls. The most important is the drop down "Blend Style" with gives options of picking between linear (gradient light similar to real life) or stepped light (segmented light more similar to cartoons/anime)
  • "Light Slider/Controller" Gives control of how much light and shadow effects the object
  • "Toon Steps" Controls the amount steps from light to dark when using any of the the stepped styles
  • "Painterly Effect Setting" drop down controls the effect of the normal map of an object.
  • "Normal Maps" Drop down allows personalized/customized/hand-painted normal maps to be added to the object

Note

  • There are plethora of options and sliders available in this suite and in each effect that this guide will not spend time covering all of. Crzyhaa video going over all of the effects is highly recommended. Choose which effects would be of interest of you.
  • https://zhaa.gumroad.com/l/wfbxv Here is a link his gumroad page which has multiple videos below explaining effects and updates made to the software

Warning

I believe this is a Mac issue but a few effects do not work such as Specular lighting, dynamic texture etc.
